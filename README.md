# wdzl

Weidian link translator (weidian -> Oopbuy / Kakobuy / Uidbuy / Hoobuy).

- Primary: https://wdzl.ores.cc/  (Tencent EdgeOne Pages, built from this repo)
- Backup:  https://wdzl.ores.qd.je/ (GitHub Pages)

## Features
- Multi-line weidian URL input, per-channel output
- Batch TSV: plain links / Google Sheets =HYPERLINK() formulas
- Per-item cards with copy buttons for link and formula
